# dyal-helm (moved)

The dyal chart now lives with dyal itself, in
[PETASUS/dyal-backend](https://gitlab.tde.sktelecom.com/PETASUS/dyal-backend) under
`deployment/dyal`, and is published from that repository's pipeline: chart X.Y.Z with
each dyal release vX.Y.Z, and 0.0.0-dev from its main branch, to
[petasus-ai/edgestack-helm](https://github.com/petasus-ai/edgestack-helm).

Nothing is published from here any more; the charts this repository published (3.5.0
and 1.0.0) stay in edgestack-helm.
